# Utilities

A collection of .NET utility libraries providing cross-cutting concerns for applications.

- **`Utilities`** — structured logging helpers (`netstandard2.0`, no backend forced on consumers)
- **`Utilities.Auth`** — OAuth consumer abstractions: provider interfaces, token models, user identity, and provider config base (`net10.0`, ASP.NET Core)

![CI](https://github.com/drrky-g/utilitites/actions/workflows/ci.yml/badge.svg)

| Package | Namespace | What's in it |

## Usage

### Logging (`Utilities.Logging`)

```csharp
using Utilities.Logging;

public class OrderService
{
    private readonly ILogger<OrderService> _logger;

    public async Task ProcessAsync(Order order)
    {
        using var scope = _logger.BeginOperationScope("ProcessOrder", order.CorrelationId);

        var sw = Stopwatch.StartNew();
        try
        {
            _logger.DependencyCallStarted("PaymentGateway", "https://pay.example.com");
            await _paymentClient.ChargeAsync(order);
            _logger.DependencyCallCompleted("PaymentGateway", 200, sw.Elapsed.TotalMilliseconds);

            _logger.OperationCompleted("ProcessOrder", sw.Elapsed.TotalMilliseconds);
        }
        catch (HttpRequestException ex)
        {
            _logger.DependencyCallFailed("PaymentGateway", sw.Elapsed.TotalMilliseconds, ex);
            throw;
        }
        catch (Exception ex)
        {
            _logger.OperationFailed("ProcessOrder", sw.Elapsed.TotalMilliseconds, ex);
            throw;
        }
    }

    public bool ValidateOrder(Order order)
    {
        if (string.IsNullOrEmpty(order.Email))
        {
            _logger.ValidationFailed("Email", "must not be empty");
            return false;
        }
        return true;
    }
}
```

### Auth (`Utilities.Auth`)

**OAuth flow** — implement `IOAuthProvider` per provider and drive the authorization code + PKCE exchange:

```csharp
// Build the provider authorization URL (PKCE challenge generated by your provider impl)
string authUrl = await provider.BuildAuthorizationUrlAsync(state, codeChallenge);

// After the user is redirected back, exchange the code for a token
OAuthToken token = await provider.ExchangeCodeAsync(code, codeVerifier);

// Retrieve the authenticated user
IAuthUser user = await provider.GetUserAsync(token);
Console.WriteLine($"{user.DisplayName} authenticated via {user.ProviderName}");
```

**Token service** — issue and validate tokens for authenticated users:

```csharp
// Issue a token for the user coming out of the OAuth flow
OAuthToken issued = await tokenService.IssueTokenAsync(user);

// Validate a raw token string (e.g. from an Authorization header)
TokenValidationResult result = await tokenService.ValidateTokenAsync(rawToken);
if (!result.IsValid)
{
    // result.FailureReason — TokenValidationFailureReason enum (Expired, InvalidSignature, …)
    return Unauthorized(result.FailureMessage);
}
ClaimsPrincipal principal = result.Principal!;

// Refresh an expiring access token
OAuthToken refreshed = await tokenService.RefreshTokenAsync(issued.RefreshToken!);
```

**Provider configuration** — extend `OAuthProviderConfig<T>` and register via options:

```csharp
// Define a provider-specific config (validates ClientId, ClientSecret, ProviderName at startup)
public class GitHubConfig : OAuthProviderConfig<GitHubConfig>
{
    public GitHubConfig() => ProviderName = "github";
}

// In Program.cs
builder.Services.Configure<GitHubConfig>(builder.Configuration.GetSection("Auth:GitHub"));
```

## API Reference

### Utilities.Logging

All extension methods live on `ILogger` in the `Utilities.Logging` namespace.

#### Operation timing

| Method | Log level | Event ID |
|---|---|---|
| `OperationCompleted(operationName, elapsedMs)` | Information | 1000 |
| `OperationFailed(operationName, elapsedMs, exception?)` | Error | 1001 |

#### Dependency / external call tracing

| Method | Log level | Event ID |
|---|---|---|
| `DependencyCallStarted(dependencyName, targetAddress)` | Debug | 2000 |
| `DependencyCallCompleted(dependencyName, statusCode, elapsedMs)` | Debug | 2001 |
| `DependencyCallFailed(dependencyName, elapsedMs, exception?)` | Error | 2002 |

#### Validation

| Method | Log level | Event ID |
|---|---|---|
| `ValidationFailed(fieldName, reason)` | Warning | 3000 |

#### Scope helpers

| Method | Returns |
|---|---|
| `BeginOperationScope(operationName, correlationId?)` | `IDisposable?` — attaches `OperationName` and `CorrelationId` as structured properties to all log entries within the scope |

### Utilities.Auth

#### Interfaces

| Interface | Responsibility |
|---|---|
| `IOAuthProvider` | Authorization URL construction, code exchange, user retrieval |
| `ITokenService` | Token issuance, validation, and refresh |
| `IAuthUser` | Represents an authenticated user (extends `IPrincipal`) |
| `IOAuthProviderRegistration` | Marker interface for DI auto-discovery (Phase 5) |

#### Models

| Type | Description |
|---|---|
| `OAuthToken` | Immutable value object — access token, refresh token, expiry, scopes, issuer |
| `TokenValidationResult` | Outcome of `ITokenService.ValidateTokenAsync` — `IsValid`, `Principal`, `FailureReason` |
| `TokenValidationFailureReason` | Enum: `Expired`, `InvalidSignature`, `InvalidIssuer`, `InvalidAudience`, `Malformed`, `Revoked`, `Unknown` |
| `AuthUserClaims` | `ClaimsIdentity` pre-populated with `NameIdentifier`, `Name`, `Email`, and `Provider` claims |
| `AuthClaimTypes` | Custom claim type constants (`auth:provider`, `auth:scope`) |
| `TokenTypes` | Token type constants (`Bearer`) |

#### Configuration

| Type | Description |
|---|---|
| `OAuthProviderConfig<T>` | Abstract base extending `OAuthOptions`; validates `ClientId`, `ClientSecret`, and `ProviderName` at startup via `IValidateOptions<T>` |

## CI/CD

GitHub Actions runs on every push and pull request to `main`, `develop`, and `dev`:

- Builds in **Release** configuration
- Runs all xUnit tests with **code coverage** (Coverlet / Cobertura)
- Uploads `.trx` test results and `coverage.cobertura.xml` as artifacts
- Targets **.NET 10**
- A single `ci-passed` gate job is provided — add that to your branch protection rules

## Adding a Backend (Optional)

`Utilities` only depends on `Microsoft.Extensions.Logging.Abstractions`.
Wire in any backend in your application host:

```csharp
// Serilog
builder.Host.UseSerilog((ctx, cfg) => cfg.ReadFrom.Configuration(ctx.Configuration));

// OpenTelemetry
builder.Logging.AddOpenTelemetry(otel => otel.AddOtlpExporter());
```
